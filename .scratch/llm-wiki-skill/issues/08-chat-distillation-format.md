# 对话蒸馏 raw 文档格式

Type: grilling
Status: resolved
Blocked by: 04

## Question

设计"当前对话 → raw 文档"的蒸馏格式与流程(用户已定:当前对话当场蒸馏,且对话中引用到的文档知识一并纳入):蒸馏指令(什么该保留——结论、决策、上下文,什么该丢弃)、raw 文档的结构与 frontmatter(来源类型 chat、身份字段)、引用文档的处理(摘要嵌入 vs 仅记录出处)、触发方式(用户指令?治理前自动?)。参考 Weft distill-chat。

## Answer

**沿用 Weft ADR-0013 全套**:正文每要点带 `[T-n]` 引用同文件转录附录;fail-closed 校验(引用可解析、编号连续,失败不写文件);`source_id = conv-<转录hash8>` 幂等覆盖;落 raw/ 即完成、不挂立即治理;raw 保留源语言(中文对话留中文)。

**skill 场景差异(写入 spec 的诚实声明)**:附录由宿主 agent 转录而非代码机械追加,保真从结构保证降级为"validate 校验内部一致性 + agent 自律"。

**用户拍板:**
- **引用文档:[R-n] 双附录方案** —— 附录 B 记录引用文档的出处+相关节录,正文 [R-n] 引用;validate 对 [T-n]/[R-n] 两类引用都 fail-closed 校验。
- **触发:手动("蒸馏"/"存进 KB")**,agent 可在对话产生重要决策时建议,不自动执行。
- **超长:转录 >30000 字符显式报错**,不静默截断,建议按主题分次蒸馏。
